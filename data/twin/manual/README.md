# Manual data downloads

Some sources need a browser login or a captcha, so they are downloaded by hand and placed
here. Files in this folder are git-ignored (except this README). Check progress with
`python scripts/twin_build.py check` from `backend/`, then build with
`python scripts/twin_build.py build --boundary-version lgd-YYYYMMDD`.

Expected files, relative to `data/twin/manual/`:

## `lgd/states.csv`

Local Government Directory, https://lgdirectory.gov.in/ -> Download Directory -> States. Export as CSV. Needs a browser session (login or captcha), so it cannot be scripted.

## `lgd/districts.csv`

Local Government Directory, https://lgdirectory.gov.in/ -> Download Directory -> Districts (with Census 2011 code). Export as CSV. Needs a browser session (login or captcha), so it cannot be scripted.

## `soi/district_boundaries.*`

Survey of India administrative district boundaries, https://onlinemaps.surveyofindia.gov.in/ (.shp, .geojson or .gpkg). Needs a browser session (login or captcha), so it cannot be scripted.

## `soi/india_outline.*`

Survey of India India outline (national boundary), https://onlinemaps.surveyofindia.gov.in/ (.shp, .geojson or .gpkg). Needs a browser session (login or captcha), so it cannot be scripted.

## `census2011/district_boundaries.*`

Census 2011 district boundaries from DataMeet, https://github.com/datameet/maps (.shp, .geojson or .gpkg). Plain download, no login. Used only for the crosswalk, never drawn.

## `census2011/pca_district*.csv`

Census 2011 Primary Census Abstract, district level, https://censusindia.gov.in/ (or data.gov.in mirror), saved as CSV.

## `viirs/VNL_*average_masked*.tif`

VIIRS annual nighttime lights, average_masked GeoTIFF for one year, https://eogdata.mines.edu/products/vnl/. Free registration and login required in a browser.

The place-name alias list lives in `data/twin/seed/aliases.csv` (committed).

This file is generated by `render_manual_readme()` in `backend/scripts/twin_build.py`.
